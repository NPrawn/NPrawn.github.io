# Backend Developer Portfolio

이정우의 백엔드 개발 포트폴리오 웹사이트입니다.

**사이트:** https://nprawn.github.io/

## 주요 내용

- **프로젝트:** AutoQuant, PinGo, Travelog, KnungAI
- **개발 경험:** 비동기 처리, 데이터 정합성 및 복구, WebRTC 실시간 통신
- **기술:** Java, Spring Boot, PostgreSQL, RabbitMQ, Kafka, Docker, Jenkins
- **이력:** SSAFY 교육, 수상 경력, 자격증 및 연락처

## 사이트 구조

- `index.html`: 반응형 포트폴리오 첫 화면. 스타일은 HTML 파일 안에 포함되어 있습니다.
- `_config.yml`: 기존 Jekyll 사이트 설정.
- `_posts/`, `_layouts/`, `assets/`: 기존 Jekyll 콘텐츠 및 테마 자산. 이전 콘텐츠를 보존하기 위해 유지합니다.

기존 [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) 기반 저장소를 활용했으며, 홈페이지는 별도의 정적 HTML로 구성했습니다. 배포는 GitHub Pages 설정을 따릅니다.
